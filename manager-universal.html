Manager Universal

A Rust MCP server that delegates coding, reasoning, and toolchain work to Claude Code, OpenAI Codex, Google Gemini CLI, or the OpenAI GPT API — through one tool surface.

Not publicly available yet. Manager Universal and its embedded dashboard are testable today, but the polished public product is not ready and the source repository is private.

This page is a capability preview. Nothing here is downloadable yet. Watch the AIWander organization for the public release.

What it does

One server replaces three separate MCP integrations — claude-runner, codex, and gemini-mcp — with a unified task lifecycle, persistent state, and a live dashboard.

Manager sits between your orchestration context and disposable coding agents. Your chat session holds the goal-level reasoning; manager handles subprocess spawning, output tailing, stall detection, retry escalation, and crash recovery. Long-running delegations survive client restarts. Failed tasks retry with backend escalation. Parallel fan-out collects results without burning orchestration tokens.

Live dashboard

An embedded dashboard runs locally during any active session, with five zones:

  • Sessions — active backend sessions with PID, uptime, and last activity
  • Active loafs — task groups in progress with phase completion
  • Active operations — running tasks with live output tails
  • Last 5 tools — recent MCP tool calls with timing
  • Retry chains — chevron-linked retry sequences showing the escalation path

Auto-pause & safety

A destructive-command heuristic classifies prompts containing operations like git push, docker push, terraform apply, or delete as potentially destructive.

Those tasks default to manual stall recovery: if the subprocess dies, the task pauses instead of auto-retrying, fires a notification, and waits for you. A paused task is not a failure — you check why and decide. Retry budgets are explicit, and previous error context is injected into the retry prompt.
